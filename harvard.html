HARVARD CS50x

CS50: Introduction to Computer Science

Prof. David J. Malan • SEAS

Harvard's flagship entry course teaching how to think algorithmically and solve problems efficiently. Covers memory, data structures, Python, and SQL.

Course Syllabus
  1. Computational Thinking & Scratch
  2. C Syntax, Arrays, and Algorithms
  3. Pointers & Dynamic Memory Management
  4. Data Structures: Trees, Hash Tables, Tries
  5. Python, SQL, and Web Frameworks
  • Introductory
  • 12 Weeks
  • C / Python / SQL

Harvard ER 22

Justice: A Journey in Moral Reasoning

Prof. Michael J. Sandel • Philosophy

One of Harvard's most renowned lecture series examining classical and contemporary theories of justice, moral dilemmas, utilitarianism, and equality.

Course Syllabus
  1. The Moral Side of Murder: Utilitarianism
  2. Putting a Price Tag on Life & Free Markets
  3. Immanuel Kant: The Categorical Imperative
  4. John Rawls: The Veil of Ignorance
  5. Aristotle: Telos and the Common Good
  • All Levels
  • 12 Lectures
  • Moral Philosophy

Harvard CS50W

Web Programming with Python & JS

Brian Yu • Harvard SEAS

Dives into the design and implementation of modern web apps with Django, React, Git, CI/CD pipelines, APIs, and scalable PostgreSQL database models.

Course Syllabus
  1. Git Version Control & Team Workflows
  2. Django: Models, Migrations, and Views
  3. Relational Modeling & PostgreSQL
  4. Modern JavaScript ES6+ & React SPAs
  5. CI/CD Pipelines, Testing, & Security
  • Intermediate
  • 12 Weeks
  • Full Stack

Harvard PH125.1x

Data Science: R Basics

Prof. Rafael Irizarry • Biostatistics

First course in Harvard's Data Science Program. Covers R syntax, data wrangling with tidyverse, reproducible visualization with ggplot2, and data frames.

Course Syllabus
  1. R Variables, Atomic Vectors, and Data Types
  2. Data Frames & Indexing Operations
  3. Tidyverse & Dplyr Data Transformations
  4. Visual Grammar Foundations with Ggplot2
  5. Vectorized Functions & Statistical Models
  • Introductory
  • 8 Weeks
  • R / Tidyverse
